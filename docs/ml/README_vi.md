# Khoá Học máy

Học máy (machine learning) là nền móng của gần như mọi hệ thống AI hiện nay, kể cả học sâu và học tăng cường. Khoá này đi từ trực giác và toán học đến mã nguồn chạy được, rồi đến cách dùng trong bài toán thực tế.

## Cách học một bài

Mỗi bài có năm trang. Hai trang đầu giúp hiểu, ba trang sau giúp làm được:

| Trang | Bạn sẽ làm gì | Kết quả mong đợi |
| --- | --- | --- |
| **1. Bài đọc** | Đặt bài toán, xây hàm mất mát, suy ra lời giải hoặc gradient | Hiểu vì sao thuật toán đúng và khi nào nó sai |
| **2. Mô phỏng** | Kéo thanh trượt, bấm từng bước, đổi dữ liệu ngay trong trình duyệt | Có trực giác về tác động của từng tham số trước khi viết code |
| **3. Code từ đầu** | Cài đặt lại thuật toán chỉ với NumPy, rồi so với thư viện | Biết từng phép tính trong thuật toán làm gì |
| **4. Dùng thư viện** | Giải lại bài toán bằng scikit-learn hoặc PyTorch | Biết các tham số quan trọng và cách so sánh các lựa chọn bằng kiểm định chéo |
| **5. Ví dụ áp dụng** | Đi trọn một bài toán trên dữ liệu thật: khám phá, tiền xử lý, huấn luyện, đánh giá, đọc kết quả | Biết quy trình làm việc thật, kể cả khi kết quả không như mong đợi |

Mọi kết quả in ra trên các trang code đều được chạy sẵn, nên bạn đọc được ngay mà không cần cài gì. Muốn hiểu sâu, hãy chép code về máy, chạy lại và thử sửa: đổi một tham số, đổi bộ dữ liệu, rồi đoán trước kết quả trước khi chạy.

Hai cách đi qua một bài:

- **Muốn hiểu kỹ:** Bài đọc → Mô phỏng → Code từ đầu → Dùng thư viện → Ví dụ áp dụng.
- **Cần dùng ngay:** Mô phỏng → Dùng thư viện → Ví dụ áp dụng, rồi quay lại Bài đọc và Code từ đầu khi gặp chỗ chưa hiểu.

## Học theo thứ tự nào

Các bài trong sách và các chủ đề bổ sung nên được học xen nhau. Một lộ trình gợi ý:

1. **Nền tảng:** [chương 5](ml/ch05_vi) (khái niệm cơ bản) → [chương 6](ml/ch06_vi) (feature engineering) → [Data preprocessing](ml/prep_vi) → [chương 7](ml/ch07_vi) (hồi quy tuyến tính) → [chương 8](ml/ch08_vi) (quá khớp) → [Model evaluation](ml/eval_vi).
2. **Các thuật toán đơn giản:** [chương 9](ml/ch09_vi) (KNN), [chương 10](ml/ch10_vi) (K-means), [chương 11](ml/ch11_vi) (naive Bayes).
3. **Tối ưu và mạng neuron:** [chương 12–16](ml/ch12_vi), từ gradient descent tới perceptron nhiều lớp.
4. **Mô hình cây:** [Decision trees](ml/tree_vi) → [Ensemble learning](ml/ensemble_vi). Đây là nhóm mô hình mạnh nhất cho dữ liệu dạng bảng hiện nay.
5. **Học không giám sát và giảm chiều:** [Advanced clustering](ml/cluster_vi), [chương 20–22](ml/ch20_vi) (SVD, PCA, LDA).
6. **Hệ thống gợi ý:** [chương 17–19](ml/ch17_vi).
7. **Máy vector hỗ trợ:** [chương 26–29](ml/ch26_vi), sau khi học phần tối ưu lồi của khoá [Toán nền tảng](math/README_vi).

Hai bài **Data preprocessing** và **Model evaluation** dùng trong mọi bài còn lại. Nếu chỉ có thời gian cho vài bài, hãy học hai bài này trước.

## Cần chuẩn bị gì

- **Toán:** đại số tuyến tính (vector, ma trận), giải tích (đạo hàm, gradient), xác suất thống kê cơ bản. Xem khoá [Toán nền tảng](math/README_vi) nếu cần ôn lại.
- **Lập trình:** Python cơ bản. Biết NumPy và pandas là một lợi thế.
- **Môi trường (nếu muốn tự chạy code):** Python 3.10 trở lên với `numpy`, `scipy`, `pandas`, `matplotlib`, `scikit-learn` 1.3 trở lên; `torch` cho vài chương về mạng neuron.

## Liên hệ với các khoá khác

Sau khoá này, bạn có đủ nền để đọc [khoá Học tăng cường](rl_vi). Các phần như hàm giá trị xấp xỉ, gradient chính sách hay DQN đều dùng lại hồi quy, tối ưu bằng gradient và mạng nơ-ron.
