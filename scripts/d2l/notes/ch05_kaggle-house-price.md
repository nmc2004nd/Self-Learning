- Hàm `preprocess` (mục 5.7.4): bản gốc chọn cột số bằng `features.dtypes[features.dtypes!='object']`. Từ pandas 3.0, cột chữ có kiểu `str` chứ không còn là `object`, nên điều kiện này chọn nhầm cả cột chữ và code báo lỗi `Cannot perform reduction 'mean' with string dtype`. Trang này đổi một dòng thành `features.select_dtypes(include='number').columns`, cho cùng kết quả như sách với pandas cũ.
- Đoạn văn trước code nói "thay giá trị thiếu bằng trung bình rồi chuẩn hóa", còn code làm theo thứ tự ngược lại (chuẩn hóa rồi thay giá trị thiếu bằng 0). Hai cách cho cùng kết quả, vì sau khi chuẩn hóa thì trung bình của cột bằng 0.
